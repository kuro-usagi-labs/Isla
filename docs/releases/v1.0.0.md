# Isla 1.0.0 — Your music, within reach

The first public release of Isla, an offline music player built around a floating,
artwork-centered island.

## Highlights
- Circular artwork with real playback progress; click to reveal playback controls.
- A dedicated expand button opens Now Playing. Controls and the expanded player gather back into artwork with fluid spring motion.
- Automatic return after 2.4 seconds idle; active clicks, keyboard input and slider drags keep controls available.
- Light, dark and system appearance, artwork accents, reduced motion and optional beat pulse driven by decoded audio.
- Ten-band equalizer, preamp, bypass, eleven presets and a saved custom curve.
- Local library, playlists, favorites, queue, shuffle, repeat and crossfade.
- Windows output-device detection and per-app output selection.

## Fixes
- Prevented a native window-state lock cycle during dragging and frequent bounds updates.
- Aligned animated artwork hit regions and retained mouse-up events during pulse/press motion.
- Preserved expanded UI layout through collapse and rapid reversal.
- Removed stale next-song notifications after expand/collapse.

## Downloads
- Windows x64: `*-setup.exe` (NSIS installer; WebView2 required).
- macOS Apple Silicon: `*_aarch64.dmg`; Intel: `*_x64.dmg`.
- Linux x64: `.deb` or `.AppImage`.

Windows is the primary tested platform. macOS and Linux are experimental builds:
desktop transparency, click-through, shortcuts and audio outputs depend on the
window manager/device. Windows startup integration is currently Windows-only.
The macOS build is ad-hoc signed, not Apple notarized. Windows installer is unsigned.

## Validation
55 frontend tests and 34 native tests passed locally on Windows before release.
Each release target is built on its matching GitHub Actions runner. Compilation
does not replace hands-on playback and desktop integration testing on that OS.

No account or streaming subscription is required. Import your own audio files;
DRM-protected streams are not supported.
