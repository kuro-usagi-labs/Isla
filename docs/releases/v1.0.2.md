# Isla 1.0.2 — Click-through hotfix

This patch addresses transparent canvas areas intercepting clicks after the
expanded player returns to its floating pill.

## Fixes

- Discard the old expanded hitbox, menu capture and pointer ownership on mode changes.
- Keep animated hit-region messages ordered and coalesce intermediate frames.
- Reject late geometry from the previous expanded/collapsed mode.
- Only retain a pressed pointer when its press originated on visible Isla UI.
- Use one native click-through writer, retry failed native updates, and refresh
  the native flag when the window mode changes.
- Ignore inert, invisible and zero-size hit regions without rejecting a valid pill region.

The main README's technical "The showcase" section and video build instructions
have also been removed. The introduction video remains on the homepage.

## Validation

61 frontend tests and 42 native tests passed locally on Windows. Regression tests
cover stale expanded geometry, transparent corners, pulse-scaled hit regions,
ordered IPC updates, pointer ownership and failed native-flag updates. TypeScript
and production builds are checked before publishing.

Manual end-to-end desktop input verification was not completed; automated
geometry/state tests do not replace testing clicks through to other applications.

## Downloads

- Windows x64: `Isla_1.0.2_x64-setup.exe` (WebView2 required).
- macOS Apple Silicon: `Isla_1.0.2_aarch64.dmg`.
- macOS Intel: `Isla_1.0.2_x64.dmg`.
- Linux x64: `Isla_1.0.2_amd64.deb` or `Isla_1.0.2_amd64.AppImage`.
- `SHA256SUMS.txt`: installer checksums.

Windows is the primary platform. macOS/Linux desktop integration remains
experimental. The Windows installer is unsigned; macOS builds are ad-hoc signed,
not notarized. Startup integration is Windows-only.
