# Isla 1.0.5 — Collapse and drag hotfix

Fixes the expanded player collapsing to artwork while its transparent canvas
continues blocking desktop clicks, and artwork becoming impossible to drag.

## Fixed

- Remove a floating-point panic in circular hit testing during pulse and morph
  motion. The panic could kill the input worker and poison shared window state,
  freezing click-through and drag together.
- Recover transient input state and release stale pointer/drag ownership.
- Keep Windows passthrough independent of monitor, drag, database and webview work.
- Expire stale expanded hitboxes and capture only visible menu surfaces.

## Validation

51 native tests and 64 frontend tests passed locally on Windows. Regression checks
cover the exact pre-fix panic, 10,000 fractional pulse frames, poisoned-state
recovery, eight real WebView2 scenarios and headless light/dark checks. Native
renderer-pointer tests verify actual window movement after collapse.

[Technical audit and regression fixtures](https://github.com/kuro-usagi-labs/Isla/blob/v1.0.5/docs/development/input-regression.md).

- macOS Apple Silicon: Isla_1.0.5_aarch64.dmg.
- macOS Intel: Isla_1.0.5_x64.dmg.
- Linux x64: Isla_1.0.5_amd64.deb or Isla_1.0.5_amd64.AppImage.
- SHA256SUMS.txt: installer checksums.

**Before upgrading, quit the old Isla instance from its tray menu.** A process
whose input worker has already crashed needs to be restarted.

Windows is the primary platform and requires WebView2. macOS/Linux desktop
integration remains experimental. The Windows installer is unsigned; macOS
builds are ad-hoc signed and not notarized. Startup integration is Windows-only.
