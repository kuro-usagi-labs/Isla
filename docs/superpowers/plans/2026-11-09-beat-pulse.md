# Beat pulse and shadow clearance implementation plan

Goal: remove the hard shadow cutoff and add an optional, audio-driven compact-pill pulse following the existing light/dark surfaces.

Design and approach: keep the 412×388 content area and enlarge its transparent native canvas from a 12px to a 48px gutter. This preserves a usable shadow even at bottom/side anchors and leaves room for pulse. Beat timing comes from short-window low-frequency energy onsets in consumed post-EQ audio, not a BPM timer (which would drift and pulse through silent sections). Bound pulse to about 1.5% width/3% height, fast attack and damped release. Suppress while paused, muted, dragging, expanded, in a notice/volume morph or reduced motion. Persist Beat Pulse in Settings, initially on. Crossfade decks contribute according to their audible gains. Native processing must not lock, allocate, emit events or alter samples on the audio callback.

Execution: inline, within the user's explicit implementation request and existing delegated design direction. Source backup: `.codex-backups/before-beat-pulse.zip`; workspace has no Git repository.
