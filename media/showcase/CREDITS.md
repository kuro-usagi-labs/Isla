# Launch film credits

Camera and renderer adapted from [Barty-Bart/motion-graphics](https://github.com/Barty-Bart/motion-graphics)
(MIT); installed skills and copyright notice are in `.agents/skills/`.
UI springs and color interpolation use [Motion](https://github.com/motiondivision/motion).
Application markup and geometry are from Isla's production React components.

Original synthesized score: `scripts/build-showcase.mjs`, 96 BPM.
