# Isla motion showcase

24 seconds · 1920×1080 · 30 fps · H.264/AAC MP4.

One continuous application object. No promotional slides, screenshots, stock
footage, feature paragraphs or title-card cuts. Only the Isla brand and a single
footer line sit outside the application.

The production React components supply the markup. Production liquid-island and
equalizer geometry are bundled for the browser. Motion's spring generator uses
stiffness 240, damping 26, mass .85; every state is derived from absolute film time.
Hyperframes seeks and renders the composition; the GSAP root is only its clock
adapter. No network assets, timers or random animation state.

0–4.6s: artwork, split controls, pause response and merge.
4.6–8.2s: artwork expands into Now Playing; seek thumb and fill move.
8.2–11.85s: EQ drawer opens; gains, thumbs, fills and curve move together.
11.85–15.5s: drawer closes, theme moves to dark, expanded UI gathers into artwork.
15.5–21.4s: dark split, merge, volume HUD and return to artwork.
21.4–24s: resting artwork with a gentle beat response.

The film uses an original 96-BPM synthesized score. The displayed demo track is
fictional. Demo pulse is staged to that score; the application itself measures
onsets from decoded audio. No copyrighted music or third-party track artwork.
